# Changelog

One entry per commit, newest first, generated from the full repository
history and extended by hand since. Entries marked [page] modified
index.html. Every commit that modifies index.html adds its own dated
entry to this file — CHANGELOG.txt is the single canonical changelog,
served by the site and linked from the header.

  (id alltime_buffed), the All-Time item pool simmed fully raid-buffed,

- [data] The flame-cap instrument is renamed flame_cap_proxy in the
  stored profile, shirt line and APL use_item line together, because
  the bare name collides with the real DBC item Flame Cap and the
  synthetic-naming rule hard-fails it. The rename is verified

  item_t::initialize_data() only downloads DBC data when an id is

  the flame-cap buff missing, the bare name was load-bearing there
  and the rule saved the profile family from a silent drop.
