# 2. ACID RAIN: on-use DAMAGE proxy on the SHIRT. cd=20 holds ~90% uptime to match the log now that
#    the shared item cooldown is off (at cd=18 with no shared lock it would run ~100% and over-credit).
# 3. ASCENDANCE: synthetic on-use HASTE on trinket1 (use=170haste_20dur_180cd). Fires clean because:
#      a) default_item_group_cooldown=0 removes the 20s shared lock that was starving it (proven: the
#         vers trinket went from Start ~1.0-1.4 to a clean 3.0 once this was set).
#      b) NO line_cd on its use line. The item is already 180cd, so line_cd is redundant -- and on an
#         off-GCD use_item it blocks the line entirely (that was the "buff never appeared" bug).
#    The item's own 180cd gives 2 uses (Start ~2.0). 170 haste ~= +25% multiplicative
#    (21.39% -> ~51.7% effective). Tune the 170 to your in-game Ascendance char-sheet haste.
# LvB damage fix: resto drops Lava Burst's crit-chance scaling; +16.4% coef bump (1.38996->1.6184) to match log's 6.1k Avg Hit @24.86% crit. Fixed for this crit level, doesn't scale.
